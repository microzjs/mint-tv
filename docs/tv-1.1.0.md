# TV 交互与网络适配 · 1.1.0

## 交互规则

主页采用分类、频道、预览三栏。分类上下移动焦点即可筛选频道，不需要额外按确定；右键进入频道，确定立即全屏。初次启动焦点位于频道列表。电视设备再次启动时优先恢复上次频道。

全屏状态无可见的右下角返回按钮。确定键打开左侧选台面板，左右在分类和频道两列间移动；浏览分类仅更新面板，不调用播放器 prepare、stop 或 release；确定另一个频道后才切换媒体项。返回先关闭面板，再返回主页。菜单键仍可手动选线路。

## 适配策略

识别请求由运行应用的设备自身发出，使用 HTTPS `myip.ipip.net/json`，失败或无法识别时尝试 `ipwho.is`。只接受验证过的 31 个省份 ID 及 mobile/telecom/unicom 三类运营商，不允许接口数据直接拼接任意仓库路径。

当前生效的缓存和已识别网络分开保存。成功下载且解析到至少一个频道之后，在同一个 SharedPreferences 提交中切换缓存、当前省份、当前运营商和更新时间。下载失败、列表为空、境外出口、未知 ISP 或识别接口限流时保留上次成功的源。

匹配键只有“省份 / 运营商”，不包含 IP 数值；同省同运营商更换公网地址时仍沿用原源。每日列表更新独立于匹配键。网络回调采用默认网络、连通验证与去抖，避免每次能力通知都重复查询；前台额外每 15 分钟复查。后台每日任务也会识别网络，再更新当前匹配的列表。

手动模式保存单独的省份/运营商覆盖值，后续停止自动公网识别；选择自动模式后重新检测。已有导入和收藏不会因网络匹配而移除。代理和 VPN 可能让识别接口看到不同出口，不能保证定位为真实接入运营商，因此保留手动入口。

识别服务会收到请求的公网 IP；应用不保存 IP，也不传送到开发者服务器。首个离线启动继续使用附带的福建移动备用快照，不会清空频道。

## 验证状态

2026-11-22：本地 release 构建、Android Lint、8 项网络响应单元测试通过。独立测试覆盖省份中文/英文别名、陕西与山西区分、93 个有效省份/运营商组合、同网保持、换省/换运营商、未知或境外出口、路径校验及原有播放列表解析。

电视盒子为 Android 14 / 1080p Google TV。已检查旧版与新版签名相同。根据用户要求，已先获得明确同意，再通过 ADB 覆盖安装至指定盒子。现场识别结果为福建移动；日志确认 NETWORK_MATCH fujian/mobile 和 NETWORK_RETAIN fujian/mobile。已使用遥控器按键验证全屏确定打开面板、左右切换分类/频道、浏览卫视分类时 CCTV2 画面继续变化、确定安徽卫视后换台出画面，以及返回主页继续预览。全屏无右下角返回按钮。首次观察受到用户同时操作遥控器的影响，不将其作为误换台的证据。确认键按下/抬起仍做成对处理，避免打开面板的同一次按键被新列表复用。现场没有实际更换到另一省份或运营商；这些分支以规则和响应单元测试覆盖，未逐条检测所有线路。

每日任务在已注册时不重复调度，避免每次打开应用重置周期而触发额外下载。测试已使用原生 screencap 与按键注入，未使用会改变旋转锁定状态的 UIAutomator。
