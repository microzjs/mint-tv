# 薄荷电视 1.6.1

本次正式版包含 1.6.0 的源下载容错、恢复入口、高清试播改进，并新增：

- 首页“薄荷电视”后显示实际安装版本，设置标题也读取实际版本。
- 设置 → 系统更新：手动检查 GitHub 最新正式 Release；有新版本自动下载并调用盒子系统安装器，无更新时提示当前已是最新版。
- 只接受本仓库对应版本的 APK；检查大小、发布资源的 SHA-256（如有）、包名、版本号和现有安装签名。下载失败、取消或校验失败均不卸载、不清空数据。
- Android 8 及以上首次更新可能需要用户允许本应用安装更新；返回后继续安装。系统安装器的确认由用户完成，不提供静默安装或绕过系统授权。
- 安装包只暂存在应用私有缓存，经只读、单文件 URI 临时授权给系统安装器；没有新增常驻后台检查任务或第三方框架。

签名沿用现有设备证书，未实施签名迁移。GitHub Release 的“正式版”指非预览发布。
