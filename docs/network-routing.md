# 直播直连说明

前台直播与后台试播均设置 `Proxy.NO_PROXY`，优先将 socket 和 DNS 绑定到 Android 可用的非 VPN 物理网络。GitHub 列表更新、节目单与台标仍按普通网络路径访问。

这不能强制绕过软路由的透明代理，也不能保证 Android VPN 的锁定 / 禁止绕过模式允许直连。应用不修改路由器配置，不会更改系统全局代理设置。

Clash / 软路由建议：把大陆 IP 的 DIRECT 规则放到兜底代理规则之前；GitHub 域名仍使用你原有的代理规则。例如保留 GitHub 规则，再使用 `GEOIP,CN,DIRECT`。实际策略组名称、规则顺序、DNS / Fake-IP 和透明接管配置需按你自己的配置调整。

盒子整体直连或将整个应用排除于 VPN 之外，也会影响 GitHub 更新；若希望 GitHub 走代理而国内直播直连，优先按目标域名 / IP 分流。

本次没有登录或修改你的软路由 / Clash，也未据此宣称全部流量已经绕过代理。
