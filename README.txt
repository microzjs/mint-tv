薄荷电视 1.1.0

电视遥控器操作
• 主页左侧是分类，中间是频道，右侧是播放预览。分类获得焦点后上下移动即可切换；右键到频道列表，确定直接全屏观看。
• 全屏按确定：左侧弹出分类和频道列表，当前直播继续播放；左右切换分类列/频道列，上下浏览，确定新频道才换台。
• 返回键先收起选台面板，再返回主页；主页返回可确认退出。全屏不显示右下角返回列表按钮。
• 未展开选台时，上下快捷换台，左键选分类，右键/菜单键选择线路。
• 电视端再次打开，自动继续上次频道。主页设置和导入仍可用。

网络与源适配
• 首次联网、重新进入应用、网络变化及周期检查时，由盒子访问 HTTPS 公网识别服务，匹配中国大陆省份与移动/电信/联通。
• IP 数值改变，但省份和运营商相同，不重新选择源；列表仍每日更新。
• 省份或运营商变化时，下载 CHINA-IPTV 对应 Unicast 列表，验证有频道后同时更新列表和匹配信息。识别失败、列表为空或下载失败均保留原可用缓存。
• 没有可用识别结果时，初始备用源是安装包附带的福建移动快照。设置→网络适配可手动选择省份、运营商，也可切回自动模式。
• IPIP（myip.ipip.net）为首选识别服务，失败时尝试 ipwho.is。服务方可看到访问的公网 IP；应用只保存省份、运营商和检测时间，不保存公网 IP。选择手动模式后不再主动自动识别。
• VPN、代理或公网定位误差可能造成误配。网络匹配只决定优先列表，不保证所有频道都可播或总是延迟最低；播放器仍按线路原顺序试播，报错或 14 秒未出画面/缓冲超时后切换备用源。

导入和更新
• 支持 M3U/M3U8/TXT 文件以及 HTTP/HTTPS 订阅网址。
• 导入源保留在本机，不随自动地区切换被删除。网址订阅随每日任务刷新，本地文件保留原内容。
• 更新失败保留原列表。系统休眠或断网可能延后每日任务。

开发

独立解析和地区规则测试运行 scripts/test-playlist.ps1（Windows）或 bash scripts/test-playlist.sh。
安装包签名与当前盒子 1.0.1 一致，可覆盖升级；不应卸载以免清除导入和收藏。
