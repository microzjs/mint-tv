# 薄荷电视 1.6.0

- 内置公开频道列表增加备用下载地址，限定总下载预算，失败保留已有频道。
- 主界面“重试”提供重试播放、更新重检、选择地区和检查网络入口；空频道列表也可按确定恢复。
- 没有前台播放时，为软件解码失败的源追加一次有时间限制的硬解验证；开始观看前取消后台硬解，优先保障直播。
- 记住实际观看成功的源与分辨率，后续换台参与高清排序；后台补验仅针对尚未确认的源。
- 清理历史模块、组播锁和失效文档引用；保留宁夏与河北卫视画幅修正。

本轮不增加版本提醒、备份入口或签名迁移，不改变证书及覆盖安装路径。
