# 1.2.0：频道源健康缓存与播放状态

## 检测与缓存
首次进入已匹配省份/运营商的网络，后台 JobService 对当前频道快照中的全部源逐一静音试播。结果及当前频道/源游标提交到本机 SharedPreferences，中断后接着检测，不从头开始。每 4 分钟主动让出一次任务，由系统继续调度。系统限额、休眠、断网会延后完成。

检测使用独立播放器与离屏视频 Surface，以首帧为成功判据；不申请音频焦点、不输出声音，优先软件解码以减少争用前台硬件解码器。无法使用软件解码、资源不足等结果标为“不确定”，不因此隐藏一个可能可播的频道。网络错误或 14 秒未出首帧为失败。当前应用不支持的 RTP/RTSP 地址判为不可用。

缓存范围为省份/运营商，另有检测代次令牌防止旧网络的异步结果写入新缓存。检测完成后，同一范围再次启动只读取结果，不重复全量检测；未完成的任务继续原进度。日常频道源更新不触发重新全量检测。新增或变更的源可由用户手动重新检测。

选台时按频道当前源的原始顺序，选择缓存中第一个成功的地址；地址已经被远端移除时，退回正常顺序试播。缓存成功不保证该源永久在线，播放期间仍保留原有出错切线能力。

## 隐藏与恢复
仅在所有源均得到失败结论时隐藏频道，主页、分类、收藏、全屏侧栏及快捷换台均过滤隐藏频道。未检测和不确定状态保持可见。手动重检时保留既有缓存；原来隐藏的频道只有获得成功结果后才恢复，不因一次不确定结果提前出现。

入口：设置 → 检测 / 网络 → 重新检测所有频道。检测进度显示已处理频道和隐藏数量。省份/运营商改变并成功匹配新源后会开始新一轮检测。不会删除用户导入或收藏数据。

## 右上角状态
全屏按确定打开左侧选台时，右上角同时显示每秒更新的状态；关闭选台面板后隐藏状态，避免长期遮挡。显示实时下载流码率、视频格式和标称码率、分辨率、音频编码、声道数、采样率，以及实际音视频解码器名称。

下载流码率是前台播放器网络读取字节的实际采样，包含音频及封装，受 HLS 分片与缓存影响，可能短时为零；不把它冒充精确的视频 elementary-stream 编码码率。源未提供标称码率时显示未知。

## 验证（2026-11-23）
本地 release 构建、Android Lint 和 14 项单元测试通过。单元测试覆盖未知状态不隐藏、原隐藏频道仅在成功后恢复、所有失败时隐藏、空结果不判失败，以及网络响应解析。

已取得用户明确同意后覆盖安装到指定的新电视盒子。现场观察到后台任务运行、进度从 14 / 119 延续到 54 / 119 个频道，更新后未重置；已隐藏 1 个全源失败频道且直播继续播放；右上角显示 AVC 1080p、AAC、2.0 声道、32kHz 及实际解码器，下载流码率持续变化。完整首轮仍在后台执行，不能将已出首帧等同于已验证所有节目内容或长时间稳定性。现场未实际迁移省份/运营商，亦未对每一个隐藏频道的恢复作逐一实测。

重开应用后的日志直接出现 FIRST_FRAME CCTV13 source=2，验证使用缓存第三条成功源，未再经历前两条 HTTP 失败。
