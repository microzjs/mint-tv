# 1.3.0：轻量优先的前两步迭代

本次按“功能实用、界面简洁、控制运行内存”的原则完成存储与日常操作改进。未添加运行时依赖，仍使用原生 Android 控件及 Media3。录像、多画面、云账号和大型节目墙不在本次范围。

## 第一步：存储与数据安全

- `LocalState` 在 IO 线程首次加载旧 `mint.xml`，保留原文件。后续以 `files/state-v1` 为准，旧文件只作迁移留底，不参与日常读写，也不保证降级后包含新设置。
- `StateDisk` 将源列表、检测任务、结果、进度、节目单和设置分为独立 JSON 桶；写入新一代文件并 fsync，通过索引切换提交。中途出现备份索引时恢复上一完整代；读取异常不自动清空数据。
- 界面使用内存快照；频道列表和健康 JSON 只在对应文本变化时解析一次。后台线程合并写入；检测推进不会重写源列表桶。未完成的极短合并写窗口在异常强杀时可能重复检测，不能承诺每个毫秒都落盘。
- 播放切台时暂缓后台试播，内存压力时退出本次检测切片，交由系统重试；受前台压力影响的试播不记录为失败。
- 设置 → 更多设置 → 导出本地备份 / 从本地备份恢复。使用系统文件选择器，包含订阅内容、收藏、最近观看、频道编号、网络手动设置和节目单地址。导出文件明文，订阅凭据应由用户自行保管。
- 恢复先校验格式、字段、网络标识、地址、列表和编号，再确认覆盖；整批数据成功写盘后才替换内存。不带入检测结果和节目单缓存，避免跨盒子/跨网络沿用判定。无系统文档选择器的盒子会提示安装兼容文件管理器。

## 第二步：遥控器日常操作

- 列表显示稳定频道号；更新源时按频道名称标识保留原号码，移除频道的号码暂保留，返回后沿用。上限 5000 个记录，号码范围 1–9999。
- 遥控器数字键或数字小键盘输入最多四位，1.4 秒后选台，按确定立即选择，返回取消。隐藏频道不能通过数字键绕过检测。
- “最近观看”分类最多保留 20 个最近选择的频道，按最近顺序排列，隐藏或已移除频道不显示。
- 设置 → 更多设置 → 隐藏频道管理，查看最后检测时间，选择某一频道单独重检；播放时线路菜单也能重检当前频道。已完成的全量检测不被清空，单频道任务可中断续检。只有实际成功才恢复，未知不当作失败；本轮不确定时保留以前可播地址供前台尝试。
- 可选 XMLTV / XMLTV.gz 地址，按 `tvg-id` 或精确频道名称匹配。流式解析，最多缓存每频道当前/下一节目，不下载台标。每 6 小时尝试更新；手动保存可立即更新，失败保留同一配置的缓存，过期内容不冒充当前节目。主页预览及全屏确定后的右上信息区显示节目。
- XML 解压后上限 32 MB，文本及条目数有限制；禁止外部实体读取，不访问外部 DTD。普通 XMLTV 外部 DTD 声明可忽略，自定义实体扩展被拒绝。

## 构建与签名

```powershell
.\gradlew.bat :app:assembleCompat :app:assembleRelease :app:lintDebug :app:lintRelease :app:testDebugUnitTest
.\scripts\test-playlist.ps1
```

- `compat`：使用本机原有 debug key，启用 R8 / 资源压缩，专供现有开发版覆盖测试。签名未更换，因此可以 `adb install -r` 保留应用数据；不可把该包宣传为独立正式签名。
- `release`：启用 R8 / 资源压缩。通过 `MINT_KEYSTORE`（本地密钥绝对路径）、`MINT_STORE_PASSWORD`、`MINT_KEY_ALIAS`、`MINT_KEY_PASSWORD` 配置独立生产证书；四项需同时设置。未设置时仅生成 unsigned APK。
- 本次没有生成或上传私钥，没有配置 GitHub Secrets。今后切换正式证书通常无法直接覆盖原开发版，应先导出备份并由用户决定迁移；禁止用卸载来规避安装失败而丢失数据。
- CI 保持仓库只读权限，上传测试 Debug 和 unsigned Release。CI 临时 debug 签名不能保证覆盖这台盒子。

## 验收边界

本地测试覆盖文件持久化中断恢复、损坏文件保留、分桶写入、备份校验与往返、编号与最近记录、XMLTV 当前/下一/时区/匹配/实体/容量限制，以及原有网络判定和隐藏规则。构建与 Lint 结果另见本次交付记录。

盒子覆盖安装需要用户单独授权；安装前的本地构建和 JVM 测试不能替代 Android 真机的迁移、遥控器、文件选择器、软件解码资源和 R8 回归。没有据此宣称运行内存降低了固定百分比。公网节目单实际覆盖率取决于用户地址和频道标识，不随包内置未经验证的第三方 EPG。
